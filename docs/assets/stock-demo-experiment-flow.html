股票决策辅助场景：信息复用与意图调整如何转化为可观察 Benefit
系统级比较：Chat-only 以语言为唯一操作通道；Chat + Widget 将信息和当前策略转化为可操作对象

实验任务

从 ALFA、BETA、GAMMA 中选择一只值得进一步研究的股票

提交 100—150 字选择理由，并指出至少一项待核查风险

共同只读初始阶段

相同的静态走势图、文字事实与 Initial Intent

参与者先提交初步候选与一句理由，形成判断锚点

随机分配
交互条件

Chat-only

通过语言重新指明、复用已有信息

通过 Chat 修改策略，Agent 用文字总结当前策略

Chat + Widget

点击信息对象：关注 / 加入依据 / 调整条件

Strategy Object 持续可见，支持 Diff 与 Undo

等价任务信息与 Agent 逻辑

两组获得相同的数据、事实解释与 Mock Agent 状态逻辑

差异在交互结构，以及信息和意图是否成为持久、可操作的共享对象

新增约束：形成多目标权衡

半年内可能需要 30% 资金，因此更重视可变现性、经营稳定性与下行风险

但剩余资金仍希望保留一定增长潜力

L2｜已有信息二次消费

重新使用早期出现的现金流、客户集中度、估值和负债信息

任务同时包含相关事实与合理干扰信息

L3｜用户意图调整

调整期限、风险偏好、流动性要求与增长目标

Agent 不得静默改变策略，所有变化需用户确认

有依据的策略修订

Exposed → Focused → Evidence → Intent Updated → Used

场景中的具体 Benefits

① 降低既有信息的重新定位与复用成本　② 更准确地完成意图调整

③ 使最终理由与当前策略一致　④ 减少关键风险遗漏

可观察终点

首次正确引用 · L2完成时间 · Intent调整时间 · Chat轮数 · 输入字符数｜Intent准确率 · 相关依据比例 · 风险遗漏率｜认知负荷 · 控制感 · SUS
