# CHI论文初稿—股票V3.3协调说明 V1.0

> 日期：2026-08-27  
> 核对来源：`CHI_v6.pdf`第5节Study 2、第6—8节Discussion/Limitations，以及股票V3.3剧本、对象表、Benefit与Metric  
> 用途：约束论文和实现的一致性；不是新的Benefit或结果文档

## 1. 总体裁决

V3.3与论文的上位机制一致：Chat保留为开放入口，Agent输出中的稳定领域节点可以被重新访问并承载局部状态操作，从而降低从“找到相关信息”到“完成状态更新”的信息边成本。两者都不应被解释成Graph优于Text，也不主张Widget自动提升投资判断能力。

但论文初稿的“Historical Investment Research”与V3.3不是同一份实验材料。初稿描述了四个独立output-contingent triggers、Source/Risk/Claim/Assumption等对象、OCFT主指标、72人Study 2和完整显著结果；V3.3是一个8轮、19个早期事实、一个复合中间约束触发器、Strategy/Evidence共享状态和`joint_success_time_gain_H`主指标的待运行实验。不得把二者拼接成同一方法与结果。

## 3. 论文必须修改的内容

### 3.1 数据与结果

在没有真实完成Study 2并锁定数据前，必须删除或显著标注为占位的内容包括：

- Study 2的72名参与者、576个timed episodes及所有招募分布；
- Table 4—8和Figure 8中的OCFT、准确率、F1、风险覆盖、显著性和效应量；
- `77c`、`21c`、`3.7×`、`0 turn`等示意成本；
- “generalized across all three domains”等经验性结论。

公开Demo、代码可用或界面可运行都不能替代参与者数据。

### 3.2 方法二选一，不可混写

论文团队需要在正式提交前选择：

1. **保留初稿四触发器投资arm**：另行实现和运行对应材料；V3.3只作为独立原型/补充设计案例，不能提供该arm结果。
2. **用V3.3替换投资arm**：将5.3、5.5、Table 4投资行、Table 7和相关结果全部改为8轮复合episode、19个事实、Strategy/Evidence状态和V3.3 Metric；重新确定样本量与统计模型。

当前默认采用第2种方向用于后续协调，但在团队书面裁决与真实采集前，论文不得声称已经完成该Study。

### 3.3 Claim措辞

可以写：

> 在内容等价的多轮探索任务中，相比以Chat为唯一状态操作通道，Chat + Widget使既有信息和共享Intent状态成为可直接访问、检查和操作的节点；我们检验这是否提高质量门控后的复用与调整效率。

尚不能写：

- “已经显著降低3.7倍交互成本”；
- “提高了投资决策正确率”；
- “自动发现了最重要对象/用户意图”；
- “OCFT显著下降”或任何方向明确的实证结论；
- “适用于所有复杂Agent任务”。

## 4. 正式数据采集前仍未解决

1. 至少三名独立审阅者完成Round 05文案到五个Strategy字段的内容效度映射；
2. 冻结对象注册表的完整来源、period/window、detail、关系和版本；
3. 冻结Chat解析同义表达、澄清和确认协议，并用Golden Log验证两条件状态等价；
4. 冻结`H`、`L`、样本量/MDE、随机化/配对结构、评分codebook和SAP；
5. 决定论文使用V3.3 Primary还是重构为统一OCFT；
6. 完成部署后工程验收与无登录访问检查；
7. 经伦理/同意流程确认后才能开始正式招募和确认性数据采集。

## 5. 当前Review结论

V3.3已经达到**公开原型实现**所需的一致性标准：理论机制、场景Benefit、对象状态和两条件差异可以被实现与演示。它尚未达到**正式确认性实验**冻结标准，因为H/L、样本量、内容效度映射、评分与SAP仍未完成。后续公开网页必须标注“研究原型/虚构数据/非投资建议”，不得显示论文占位结果或暗示已验证效果。
